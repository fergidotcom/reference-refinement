**Code Locations**:
- Context editor modal HTML: Lines 6044-6134
- JavaScript functions: Lines 4597-4923
- Context button: Line 2697 (in createReferenceCard)

**Cascade Workflow**:
1. User edits context in textarea
2. Checkbox: Regenerate Relevance → Claude API generates 2-3 sentence summary
3. Checkbox: Regenerate URLs → Generate queries → Google Search → Claude ranking → Assign Primary/Secondary URLs
4. Auto-save to Dropbox
5. Refresh UI

**Known Limitations**:
- .docx manuscript extraction not implemented (requires mammoth.js library)
- Manuscript search shows placeholder message
- Context expansion requires .docx parsing
- **Workaround**: Manual paste workflow fully functional
